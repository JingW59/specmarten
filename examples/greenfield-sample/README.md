# Greenfield Sample

This is a minimal OpenSpec project for trying the new-project SpecMarten flow.
It has baseline specs, but no active or archived changes yet.

Copy the sample to a scratch directory, then run:

```sh
specmarten init --minimal
specmarten status
```

The expected project type is `greenfield`, and the next step is to draft the
roadmap with `$specmarten-plan`.

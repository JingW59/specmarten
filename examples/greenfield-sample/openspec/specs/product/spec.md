# Product Spec

## Purpose
Define the starting point for a new project before any OpenSpec changes are
opened.

## Requirements

### Requirement: Reviewed Roadmap
The product MUST start from a reviewed roadmap before implementation changes
are opened.

#### Scenario: Planning before changes
- **GIVEN** a new repository with no OpenSpec changes
- **WHEN** SpecMarten is initialized
- **THEN** the next step is to draft a roadmap through the client-first planning flow

# Code of Conduct

SpecMarten uses a simple project conduct standard: be respectful, assume good intent, and keep discussion focused on improving the project.

## Expected Behavior

- Be clear and constructive when reporting problems or reviewing changes.
- Respect different experience levels and tool choices.
- Discuss technical disagreements with concrete examples, logs, or reproduction steps.
- Keep security-sensitive details out of public issues until a private reporting path is available.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Personal attacks or repeated off-topic arguments.
- Publishing private information without permission.
- Deliberately disruptive behavior in issues, pull requests, discussions, or release channels.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests; block participants; or take other reasonable action to protect the project. If you need to report conduct concerns, open a minimal issue asking for a private contact path and do not include sensitive personal details publicly.
